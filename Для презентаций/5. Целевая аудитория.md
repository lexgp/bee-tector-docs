# Анализ потребительских сегментов

## Стартап: система мониторинга болезней и паразитов пчёл (Varroa)

---

## 1. Обзор рынка и контекста

Паразит Varroa destructor - одна из ключевых проблем пчеловодства.

* Потери пчелиных семей в мире: **20–40% ежегодно**
* Основная причина: варроатоз + вирусы
* Контроль осуществляется:

  * вручную (осмотр)
  * химическими обработками
  * нерегулярным мониторингом

Ключевая боль:

> Пчеловоды узнают о проблеме **слишком поздно**, когда семья уже ослаблена или погибает.

## 2. Сегментация пользователей

### 2.1 Любительские пасеки (90%)

#### Характеристика

* 1–50 ульев
* 1–2 человека
* Доход не основной
* Возраст часто 45+

#### Ключевые проблемы

* Недостаток знаний и системности
* Проверки нерегулярны
* Высокая смертность из-за ошибок
* Склонность к «народным методам»

#### Потребности

* Простые и дешёвые решения
* Минимум настройки
* Понятная визуализация ("есть клещ / нет клеща")

#### Поведение

* Чувствительность к цене: **очень высокая**
* Склонность к покупке: **низкая**
* Доверие к технологиям: **низкое**

#### Вывод

**Не приоритетный сегмент для MVP**
Можно заходить позже через:

* дешёвую версию
* мобильное приложение
* B2C канал

---

### 2.2 Фермерские пасеки (8–9%) !ЦЕЛЕВОЙ СЕГМЕНТ

#### Характеристика

* 50–300 ульев
* 2–4 человека
* Основной доход — мёд
* Кочевая модель

#### Ключевые проблемы:

1. **Поздняя диагностика Varroa**

   * заражение видно, когда уже поздно

2. **Перерасход химии**

   * обработка «на всякий случай»

3. **Высокая трудоёмкость**

   * регулярные выезды
   * ручные проверки

4. **Неоптимальный тайминг обработки**

   * либо поздно → гибель
   * либо рано → лишние затраты

5. **Потери медосбора**

   * ослабленные семьи дают меньше мёда

#### Потребности

| Потребность         | Как этого добиться            |
| ------------------- | ----------------------------- |
| Снижение смертности | Раннее выявление Varroa       |
| Рост выработки мёда | Контроль здоровья семьи       |
| Меньше поездок      | Удалённый мониторинг          |
| Упрощение проверки  | Автоматический анализ         |
| Снижение химии      | Точечные обработки            |
| Экологичность       | Контроль без «ядов»           |

#### Экономика проблематики

* Потеря 1 семьи: ~5000–15000 рублей
* Потери при 100 ульях: **до 20–30% → сотни тысяч рублей**
* Химия и труд: существенные расходы

Чем могбы помочь продукт:

* снижает потери хотя бы на 10–20%
* экономит 20–30% времени

тогда он **окупается за один-два сезона**

#### Поведение ЦА

* Открыты к технологиям (если есть ROI)
* Готовы тестировать
* Важен **быстрый эффект**

#### Вывод

**Главный сегмент для MVP и продаж**

---

### 2.3 Промышленные пасеки (1%)

#### Характеристика

* 300–1000+ ульев
* 5–20 сотрудников
* Бизнес-процессы, бюджеты

#### Проблемы

* Масштабируемость контроля
* Контроль персонала
* Потери → миллионы рублей в год

#### Потребности

* Централизованный мониторинг
* Аналитика
* Интеграция с IT-системами

#### Поведение

* Готовы платить много
* Но цикл сделки длинный
* Требуют:

  * надёжность
  * доказанную эффективность

#### Вывод

**Не для старта, а для масштабирования**

## 5. Конкурентные альтернативы (как сейчас решают)

1. **Ручной осмотр**

   * долго
   * неточно

2. **Липкие поддоны**

   * требует интерпретации
   * по прежнему нужны выезды, ручной осмотр.

3. **Химия "на глаз"**

   * дорого и вредно, не всегда применимо "в сезон"

4. **Отсутствие контроля**

   * самый частый вариант

5. **Косвенные датчики (температура / звук)**

   * причины изменений могут быть разными
   * точно численно определить степень не возможно

Вывод:

> Рынок **крайне нецифровизирован**

## 8. Итоговая стратегия сегментации

### Фокус:

**Фермерские пасеки**

Почему:

* Есть деньги
* Есть боль
* Есть мотивация
* Быстрый ROI

### Стратегия выхода:

1. MVP → фермеры (50–150 ульев)
2. Пилоты → 5–20 пасек
3. Кейсы → доказательство эффективности
4. Масштаб → крупные пасеки
5. Упрощение → выход в B2C
